## 4. Cómo reproducir contra staging

1. Cargar en GitHub (*Settings → Secrets and variables → Actions*) los secretos de los usuarios creados con `scripts/crear_usuarios.py` del backend: `CYPRESS_USUARIO_CLIENTE`, `CYPRESS_CLAVE_CLIENTE`, `CYPRESS_USUARIO_ASESOR`, `CYPRESS_CLAVE_ASESOR`, `CYPRESS_USUARIO_BACKOFFICE`, `CYPRESS_CLAVE_BACKOFFICE`.
2. Ejecutar *Actions → E2E staging → Run workflow* indicando `base_url` con la URL de Vercel desplegada contra el API Gateway de staging.
3. Descargar el artefacto `cypress-evidencia` generado al finalizar el job `cypress`.
